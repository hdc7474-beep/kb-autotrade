카톡용 브리핑 텍스트

시장 상황 · 포트폴리오 · 급등 후보 스크리너 결과를 종합해 텍스트로 만들어줘요. 복사해서 카카오톡 "나에게 보내기" 또는 정리해둔 방에 붙여넣으세요.

참고용 도구입니다. 이 브리핑은 사용자가 직접 입력한 시세·거래량·차트 값을 바탕으로 계산된 알고리즘 점수이며, 실시간 자동 시세 수집이나 미래 주가를 보장하지 않습니다. 최종 매매 판단과 책임은 본인에게 있으며, 실제 주문은 항상 토스 앱에서 스스로 확인 후 진행하세요.

오늘의 시장 스냅샷

지수 등락률과 시장 폭(상승/하락 종목 수)을 입력하면, 스크리너 점수에 반영되는 시장 국면(강세/중립/약세)을 계산해요. 값은 아래 바로가기에서 확인해 직접 입력하세요.

실시간 확인용 바로가기

앱 자체는 실시간 시세를 자동 수집하지 않아요(브라우저 보안 정책상 pykrx·거래소 API를 여기서 직접 호출할 수 없음). 아래 링크에서 값을 확인해 위 칸에 입력하세요.

네이버 국내증시 코스닥 지수 환율/원자재 Yahoo 해외증시 VIX 지수 국내 상한가/급등 순위

보유 종목 등록

국내 종목은 6자리 코드(예: 005930), 해외는 티커(예: AAPL)를 입력하세요.

보유 종목 현황

아직 등록된 보유 종목이 없어요.

급등 후보 입력

관심 종목의 오늘 데이터를 입력하면, 거래량·모멘텀·상대강도·이평선·변동성 5개 축으로 점수를 계산해 순위를 매겨요. 차트값(고가/저가/이평선)은 네이버/야후 차트에서 확인해 옮겨 적으세요.

스코어 순위 결과

가중치 · 거래량25 / 모멘텀20 / 강도위치15 / 상대강도15 / 이평추세15 / 변동성확장10

점수가 높을수록 "오늘 변동성이 크게 붙을 가능성이 있는 후보"라는 의미일 뿐, 상승을 예측·보장하지 않아요. 반드시 뉴스·재료·수급을 함께 확인하세요.

아직 입력된 후보 종목이 없어요.

포지션 사이징 계산기

"작게 잃고 크게 번다"는 리스크 관리 원칙에 따라, 계좌 대비 허용 손실 범위 안에서 매수 수량을 역산해요. 손절가를 먼저 정하고 수량을 맞추는 방식입니다.

이 스크리너가 참고한 일반 원칙

국내·해외 단기/모멘텀 트레이딩에서 공통적으로 널리 이야기되는 일반적인 개념을 종합해 채점 기준으로 삼았어요. 특정 개인의 비공개 기법을 그대로 재현한 것이 아니라, 공개적으로 많이 알려진 원칙들(수급 우선, 변동성 활용, 손절 규율 등)을 알고리즘 형태로 구조화한 것입니다.

거래량이 방향보다 먼저다평소 대비 거래량이 크게 늘어난 종목이 그날 수급 주도주가 될 가능성이 높다는, 국내외 단기매매에서 공통적으로 강조되는 원칙이에요.
변동성 확장 구간 포착평소보다 하루 변동폭(고가-저가)이 커지는 시점에 단기 기회가 몰린다는 관점으로, 해외 데이트레이딩 담론에서도 자주 언급돼요.
시장 주도 테마·상대강도지수보다 강하게 움직이는 종목(상대강도 우위)이 자금이 몰리는 종목일 가능성이 높다는 원칙이에요.
추세 정배열 확인단기(5일)·중기(20일) 이동평균이 정배열(단기>중기)일 때 상승 추세의 신뢰도가 높다고 보는 기술적 분석의 기본 개념이에요.
눌림목·고가권 위치당일 고가 대비 현재가 위치(강도)가 높을수록 매수세가 살아있다는 뜻으로 해석돼요. 다만 고점 매수 위험도 함께 커집니다.
손절 규율 & 비대칭 손익"작은 손실은 여러 번, 큰 수익은 놓치지 않는다"는 자본 보존 원칙은 국내외 단기매매 담론에서 공통적으로 가장 강조되는 부분이에요. 포지션 사이징 탭을 함께 활용하세요.

데이터는 이렇게 채워 넣으세요

국내 종목

네이버 금융(종목 코드로 검색) → 시세/거래량/이동평균은 "일별 시세", "차트" 탭에서 확인 가능해요. 뉴스는 네이버뉴스 검색 결과가 자동 연결됩니다.

해외 종목

Yahoo Finance에서 티커 검색 → Chart 탭에서 고가/저가/거래량/이동평균을 확인해 옮겨 적으세요.
